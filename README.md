
# 🏡 Tiny Town AI — The Living World

An AI-powered village simulation where 12 unique villagers
develop relationships, create memories, gossip and experience
unexpected events.

## Technologies
- Python
- Streamlit
- Ollama
- SQLite
- AI-powered conversations

## Features
- 12 unique villagers
- AI conversations
- Persistent memories
- Relationship simulation
- Gossip and random events
- Village dashboard
- AI-generated newspaper

## Installation

Install dependencies:

    python -m pip install -r requirements.txt

Download the AI model:

    ollama pull llama3.2:3b

Run the application:

    python -m streamlit run app.py

Enjoy your living village!
